# 枢元 NexusOrigin 全平台交互设计规范

## 设计核心宣言

**极简·聚焦·沉浸**  
不堆砌信息，不打断心流，让用户的每一次操作都直指目标。本规范定义枢元所有页面的统一视觉语言与交互行为，确保用户在“Agent管理、成本监控、能力市场、社区交流、任务协作”五大场景中拥有一致、高效、无干扰的体验。

---

## 一、设计哲学：认知减负法则

### 1.1 三大核心原则

| 原则 | 定义 | 落地方法 |
|------|------|----------|
| **极简** | 界面只保留当前任务最必要的信息与操作，冗余内容折叠或延迟加载 | 默认隐藏次要控件；卡片式布局；信息密度控制在每屏不超过5个可操作区块 |
| **聚焦** | 通过视觉层次和动效引导用户注意力至核心决策点 | 使用枢轴紫高亮关键按钮；聚焦面板滑入式展开详情；非活跃元素降低饱和度 |
| **沉浸** | 操作流程不跳出当前上下文，保持心理连贯性 | 所有编辑、评论、配置均在弹窗、侧滑面板或原位编辑中完成；避免页面跳转 |

### 1.2 品牌识别

- **枢轴紫** `#6C5CE7` 为主色调，代表连接、智能、可控。
- **六边形** 作为Agent符号，贯穿空状态、加载动画、图标系统。
- **命令行美学** 在部署向导、日志流、终端输出中保持黑底绿字等宽字体，强化开发者信任感。

## 二、视觉规范

### 2.1 色彩体系（亮色模式）

| 用途 | 色值 | 场景 |
|------|------|------|
| 主按钮、选中态、聚焦边框 | `#6C5CE7` | 主要操作、当前选中卡片、聚焦面板左侧描边 |
| 页面背景 | `#F8F9FA` | 全局底色，浅灰降低眼部疲劳 |
| 卡片背景、搜索栏背景 | `#FFFFFF` | 所有内容卡片、输入框 |
| 分隔线、边框 | `#E2E8F0` | 表格边框、卡片边界、分割线 |
| 主文字 | `#1A202C` | 标题、正文 |
| 辅助文字 | `#718096` | 描述、时间戳、次要信息 |
| 占位文字、禁用状态 | `#A0AEC0` | 输入框占位符、不可用按钮 |
| 成功状态 | `#00B894` | 运行中、完成、通过 |
| 警告状态 | `#FDCB6E` | 预算预警、待处理 |
| 错误状态 | `#E17055` | 失败、异常、拒绝 |
| 聚焦浅紫背景 | `#F0EDFF` | 被聚焦评论/元素背景 |
| 上下文子级灰底 | `#F9FAFB` | 子评论卡片、嵌套信息 |

> **暗色模式**：基底色 `#0D1117`，枢轴紫提亮至 `#8B7CF0`，其余色值按对比度映射。

### 2.2 字体与排版

| 元素 | 字号/行高 | 字重 | 字体 |
|------|----------|------|------|
| 页面大标题 | 24px / 1.25 | 700 | 系统默认无衬线 |
| 模块标题 | 18px / 1.25 | 600 | 同上 |
| 卡片标题 | 16px / 1.4 | 600 | 同上 |
| 正文 | 14px / 1.5 | 400 | 同上 |
| 辅助文字、标签 | 12px / 1.4 | 400 | 同上 |
| 代码/终端/数值 | 13px / 1.4 | 400 | JetBrains Mono / Fira Code |

- **全局字体栈**：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
- **行宽限制**：正文内容最大宽度 `720px`，保持最佳阅读长度。

### 2.3 间距与圆角

- **基于 8px 网格**：所有外边距、内边距、组件间距均为 8 的倍数（8, 12, 16, 24, 32, 48）。
- **卡片圆角**：`border-radius: 10px`（常规卡片），`12px`（模态框），`20px`（标签）。
- **按钮圆角**：`6px`（主/次按钮），`8px`（大按钮），`20px`（胶囊标签）。

### 2.4 图标系统

- **风格**：线性+圆角，2px 描边，24x24px 基础尺寸。
- **核心图标**：
  - Agent 节点：六边形
  - 成本闪电：能量波
  - 能力市场：拼图块
  - 聚焦：准星
  - 展开/收起：小箭头

## 三、全局布局框架

### 3.1 桌面客户端三栏动态布局

枢元桌面客户端采用 **可收缩三栏布局**，默认中间栏为主内容区，右侧信息面板按需滑入。

```
┌─────────────────────────────────────────────────────────────┐
│ 顶部导航栏 (App Header)                    [全局搜索] [用户] │
├─────────────┬───────────────────────────────┬───────────────┤
│ 左侧边栏    │     主内容区                  │ 右侧聚焦面板  │
│ 240px       │     自适应（最小 360px）       │ 380px         │
│ (可折叠)    │                               │ (默认隐藏)    │
│             │                               │               │
│ ▼ 我的Agent │   - 仪表盘卡片                │  - 评论上下文 │
│   · 翻译    │   - Agent控制台               │  - 成本溯源   │
│   · 分析    │   - 能力市场列表              │  - 问题透视   │
│   + 添加    │   - 社区帖子详情              │  - 节点详情   │
│             │                               │               │
│ ▼ 本地环境  │                               │  - 快速操作区 │
│   · Python  │                               │               │
│   · Docker  │                               │               │
├─────────────┴───────────────────────────────┴───────────────┤
│ 状态栏 (Status Bar)                                          │
│ 🟢 3个Agent运行中  |  ⚡ 今日消耗 ¥12.50  |  v1.2.0         │
└─────────────────────────────────────────────────────────────┘
```

**布局行为**：
- **左侧边栏**：默认展开 240px，可拖拽至 320px，可折叠为 48px 图标模式。
- **右侧聚焦面板**：默认隐藏，当用户点击“聚焦”按钮（评论、错误日志、成本数据点等）时从右侧滑入，宽度 380px。聚焦面板内支持递归聚焦（点击内部元素刷新面板内容）。按 `ESC` 或点击外部关闭。
- **主内容区**：右侧面板滑入时宽度自适应收缩，保证无水平滚动条。

### 3.2 移动端与Web端降级

- **屏幕宽度 < 1024px**：左侧边栏默认折叠为图标栏，点击图标展开浮层菜单。
- **屏幕宽度 < 768px**：右侧聚焦面板改为底部抽屉式，从下向上滑出，占视口 80% 高度。
- **Web端（社区/能力市场）**：采用两栏布局（左侧筛选栏 + 右侧内容瀑布流），无右侧聚焦面板（聚焦行为改为新页面或模态框）。

## 四、全局组件设计

### 4.1 聚焦面板 (FocusPanel)

**触发**：任意页面的“聚焦”按钮（准星图标）或特定元素点击（评论、错误行、成本数据点）。

**规格**：
- 宽度：380px（桌面），100% 宽度（移动端底部抽屉）
- 背景：`#FFFFFF`，顶部标题栏高度 52px，内容区独立滚动
- 动效：从右侧滑入（`transform: translateX(100%) → 0`，300ms，缓出曲线），关闭时滑出（200ms，缓入曲线）

**内部结构**：
```
┌─────────────────────────────────────┐
│  标题：聚焦视图            [X]      │
│  副标题：当前聚焦元素摘要            │
├─────────────────────────────────────┤
│  ◇ 父级评论（高亮当前）             │
│  │  └── 当前聚焦评论                │
│  │      └── 子评论1                 │
│  │      └── 子评论2                 │
├─────────────────────────────────────┤
│  [快速操作区]  回复框 / 修复按钮     │
└─────────────────────────────────────┘
```

**连接线设计**：每个上下文元素左侧绘制连接线（1px `#D1D5DB`），末端为圆形节点（直径6px），当前聚焦节点填充枢轴紫，其余浅灰。

### 4.2 按钮

| 类型 | 样式 | 状态 |
|------|------|------|
| 主按钮 | 背景 `#6C5CE7`，白色文字，圆角 6px，内边距 8px 16px | 悬停加深至 `#5A4BCF`；禁用不透明度 0.5 |
| 次要按钮 | 透明背景，1px `#E2E8F0` 边框，文字 `#1A202C` | 悬停背景 `#F8F9FA` |
| 危险按钮 | 红色边框与文字（`#E17055`），背景透明 | 悬停背景红色 10% 透明度 |
| 聚焦按钮 | 准星图标，可带文字“聚焦” | 悬停图标变枢轴紫 |
| 加载按钮 | 内置旋转器，禁用点击 | — |

### 4.3 卡片

- **基础卡片**：白底，圆角 10px，边框 1px `#E2E8F0`，内边距 16px，悬停阴影 `0 4px 12px rgba(0,0,0,0.08)`。
- **聚焦卡片**：左侧 3px 实线 `#6C5CE7`，背景 `#F0EDFF`，轻微放大 1.02 倍。
- **上下文子级卡片**：背景 `#F9FAFB`，字体颜色 `#718096`。

### 4.4 输入框与表单

- 高度 40px，边框 1px `#E2E8F0`，聚焦时边框变为 `#6C5CE7`，外发光 `0 0 0 3px rgba(108,92,231,0.2)`。
- 标签字体 13px，颜色 `#1A202C`，必填项红色星号。
- 代码/终端输入区采用深色背景 `#1E1E1E`，等宽字体，内边距 12px。

### 4.5 通知与弹出层

- **Toast**：右上角滑入，停留 4 秒，左边框彩色（绿/橙/红/蓝）。
- **模态框**：居中，最大宽度 640px，背景遮罩 `rgba(0,0,0,0.4)` + `backdrop-filter: blur(2px)`，入场缩放淡入。

- 仅当父评论展开时显示，缩进一级（`margin-left: 20px`），左边框 `2px solid #E2E8F0`，内边距8px 0 6px 12px。
