# 任务市场&任务模块页面布局样式设计
## 核心设计原则
- 清晰分层：任务信息（标题/奖励/时间）为核心层，筛选/操作为辅助层
- 视觉引导：用色彩（主色/状态色）、间距引导用户聚焦关键信息
- 响应式适配：兼容PC/平板/移动端，核心功能无断点丢失
- 一致性：组件样式、交互逻辑全页面统一（如按钮、卡片、标签）

## 一、基础设计规范
### 1. 色彩体系
| 类型       | 色值          | 用途                     |
|------------|---------------|--------------------------|
| 主色调     | #165DFF       | 主按钮、导航、重点文字   |
| 辅助色-紧急 | #FF7D00       | 紧急任务标签、高奖励标识 |
| 辅助色-完成 | #00B42A       | 已完成任务、成功状态     |
| 辅助色-失败 | #F53F3F       | 已取消/失败任务、错误提示 |
| 中性色-白  | #FFFFFF       | 卡片、页面背景           |
| 中性色-浅灰 | #F2F3F5       | 分割区、次要背景         |
| 中性色-中灰 | #C9CDD4       | 边框、占位文字           |
| 中性色-深灰 | #4E5969       | 辅助文字                 |
| 中性色-黑  | #1D2129       | 主标题文字               |

### 2. 字体与间距
- 字体：中文用「思源黑体/Inter」，英文/数字用「Roboto」
- 字体层级：
    - 页面标题：20-24px/600字重
    - 卡片标题：16px/500字重
    - 正文：14px/400字重
    - 辅助文字：12px/400字重
- 间距体系：基于8px网格（8/16/24/32/40px），保证布局规整

### 3. 其他核心页面设计要点
#### （1）发布任务页
- 分步表单：拆分为「基本信息」「奖励与时间」「要求与交付」3步，每步有进度指示
- 表单控件：输入框、下拉框、富文本编辑器、上传组件样式统一，错误提示为红色（#F53F3F），提示文字在控件下方
- 操作按钮：「上一步」「下一步」「提交」按钮区分主次（提交为蓝色主按钮，其余为中性按钮）

#### （2）任务管理页（用户中心）
- 左侧标签栏：「全部/我发布的/我承接的/已完成/已取消」，选中项高亮（蓝色背景+白色文字）
- 列表区：支持筛选、搜索、批量操作，每行显示任务标题、状态、时间、操作列（编辑/取消/确认完成等）
- 状态标签：与任务市场保持一致（紧急/完成/取消等），操作按钮根据状态禁用/启用（如已完成任务不可承接）

## 三、交互与适配优化
1. **hover交互**：卡片/按钮/链接hover时增加阴影/边框变色/文字变色，提升交互反馈
2. **响应式适配**：
    - PC端：任务列表3列布局，侧边栏显示完整
    - 平板端：任务列表2列布局，侧边栏可折叠
    - 移动端：任务列表1列布局，侧边栏转为顶部下拉菜单
3. **加载状态**：任务列表加载时显示骨架屏，避免空白页
4. **空状态**：无任务时显示「暂无任务」+ 引导文案（如「去发布第一个任务」）
5. **分页/加载更多**：任务列表超过10条时，底部显示分页或「加载更多」按钮

## 四、设计扩展建议
- 可增加「任务进度追踪」模块：承接后显示进度条（待开始/进行中/待验收/已完成）
- 增加「评价体系」：任务完成后，发布者/承接者可互相评价，评价星级展示在个人主页/任务卡片
- 增加「消息提醒」：任务状态变更（被承接/验收/取消）时，推送站内信/短信提醒
