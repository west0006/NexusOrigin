# 枢元NexusOrigin 全页面交互设计规范（修订版2.0）

# 一、仪表盘首页

## 1.1 页面定位
用户打开客户端的第一眼视图，承载“全局状态感知 + 快速行动入口”双重使命。不堆砌信息，只呈现用户最关心的三个问题：**我的Agent还好吗？花了多少钱？现在能做什么？**

## 1.2 布局结构
采用不对称三栏布局：左侧为Agent状态区，中央为成本概览区，右侧为快捷行动区。

```
┌────────────────────────────────────────────────────────────┐
│ 欢迎语 + 日期                        通知图标 + 用户头像    │
├──────────────┬─────────────────────────┬────────────────────┤
│ 我的Agent     │  成本概览               │  快捷操作           │
│ (列表卡片)    │                        │                    │
│              │  ┌─────────────────┐   │  · 新建Agent        │
│ · Agent A    │  │ 今日花费 ¥12.50  │   │  · 浏览能力市场     │
│   🟢 运行中  │  │ 本月花费 ¥386.00 │   │  · 社区求助         │
│ · Agent B    │  │ 剩余预算 ¥614.00 │   │  · 成本报告         │
│   ⚫ 已停止  │  └─────────────────┘   │                    │
│ · Agent C    │                        │                    │
│   🟡 异常    │  消耗趋势图（面积图）    │  最近使用的能力     │
│              │  ┌─────────────────┐   │  · 网页搜索工具     │
│ + 添加Agent  │  │ ╱╲  ╱╲         │   │  · 数据分析插件     │
│              │  │ ╱  ╲╱  ╲╱      │   │                    │
│              │  └─────────────────┘   │  系统状态           │
│              │                        │  🟢 网关正常        │
│              │  预算使用环形进度条      │  🟢 Sidecar运行中  │
│              │      78%               │                    │
├──────────────┴─────────────────────────┴────────────────────┤
│ 状态栏                                                       │
└────────────────────────────────────────────────────────────┘
```

## 1.3 左侧：Agent状态区（240px）

**Agent列表卡片**（每条高度56px）：
- 左侧状态指示灯：🟢运行中 / 🟡异常 / ⚫已停止 / 🔵安装中
- 中间：Agent名称 + 框架图标 + 最后活跃时间（如“3分钟前”）
- 右侧：微型Token消耗折线图（仅运行时显示，宽40px，高24px，无坐标轴）
- 点击卡片：主视图跳转至该Agent的管理页
- 悬停操作：启动/停止图标按钮浮现

**空状态**：
- 显示六边形休眠机器人插画 + “还没有Agent，点击创建第一个”按钮

**异常Agent卡片**：
- 状态灯为🟡时，卡片左侧出现3px橙色边框
- 悬停时显示异常摘要（如“API密钥过期”），点击进入管理页自动展开错误详情

**添加Agent按钮**：
- 固定在列表底部，虚线边框 + 加号图标，点击弹出框架选择引导

## 1.4 中央：成本概览区（自适应宽度）

**顶部三数字卡片**（横向排列，无边框，仅数字+标签）：
- 今日花费：大字号32px，`#6C5CE7`，下方小字“较昨日 ↓12%”
- 本月花费：大字号32px，`#2D3436`，下方小字“预计月总 ¥520”
- 剩余预算：大字号32px，颜色根据百分比动态变化（绿→橙→红），下方小字“预算 ¥1,000”

**消耗趋势面积图**（高度200px）：
- X轴：最近24小时，每2小时一个刻度
- Y轴：信用点消耗，自适应刻度
- 填充：枢轴紫渐变（`rgba(108,92,231,0.15)` → 透明）
- 描边：`#6C5CE7`，2px
- 异常消耗点用红色圆点标注
- **聚焦交互**：框选任意时段，右侧滑出消耗溯源面板（详见后文）

**预算环形进度条**（位于趋势图右下角，直径80px）：
- 进度百分比大字号居中
- 环形颜色：0-50%绿→50-80%橙→80-100%红
- 点击环形图：跳转至预算管理页面

## 1.5 右侧：快捷行动区（280px）

**快捷操作按钮组**（垂直排列，大按钮，图标+文字）：
- 新建Agent（六边形图标）
- 浏览能力市场（拼图图标）
- 社区求助（对话气泡图标）
- 成本报告（文档图标）

**最近使用的能力**（列表，最多3条）：
- 每行：图标 + 名称 + 最后调用时间
- 点击跳转至该能力详情

**系统状态指示**：
- 网关状态：绿色圆点 + “网关正常” / 红色 + “网关异常”
- Sidecar状态：绿色圆点 + “Sidecar运行中”
- 点击可展开详情

## 1.6 聚焦溯源交互（仪表盘专属）

**触发**：在消耗趋势图上框选异常时间段（或点击异常消耗红点）

**聚焦面板（右侧滑入，380px）**：
- 标题：“消耗溯源”
- 内容：被框选时段的详细调用瀑布流（详见成本监控系统）
- 面板底部：“查看完整报告”按钮，跳转至成本明细页

# 二、统一成本监控系统

## 2.1 页面定位
用户理解“钱花在哪、为什么花、怎么省”的核心页面。分三个子视图：**总览面板、明细对账、预算管理**。

## 2.2 总览面板

### 2.2.1 布局
顶部三卡片（与仪表盘数据同步但更详细），下方为可切换时间粒度的趋势图与分布图。

### 2.2.2 三卡片详细版
每张卡片在仪表盘基础上增加：
- 今日花费卡片：昨日同一时间对比线，显示“较昨日同时段 ±X%”
- 本月花费卡片：按当前速率预计月末总花费，超预算时红字警告
- 剩余预算卡片：进度条微缩版内嵌，显示“剩余X天，日均可用¥XX”

### 2.2.3 趋势图（完整版）
- 时间切换：24小时 / 7天 / 30天 / 自定义范围
- 粒度自适应：24小时按小时聚合，7天按天聚合，30天按天聚合
- 双Y轴：左侧信用点金额，右侧Token数量
- 异常标注：自动检测消耗突增3倍以上的时间点，红色竖线标注
- **聚焦**：点击任意数据点，右侧面板展示该时间点的Top消耗任务

### 2.2.4 成本分布图
- 三组环形图/饼图，并列展示：
    - 按模型分布（GPT-4o / Claude / DeepSeek / 本地模型）
    - 按Agent分布（Agent A / Agent B / Agent C）
    - 按任务类型分布（对话 / 代码生成 / 翻译 / 搜索）
- 点击饼图扇区：筛选下方明细列表

### 2.2.5 智能降本建议卡片
位于趋势图下方，横向滚动卡片组，每条建议一张卡片：
- “检测到高频重复查询，开启语义缓存预计节省30%” → [一键开启]
- “检测到简单任务使用高价模型，建议切换至GPT-3.5 Turbo” → [一键切换]
- “检测到未被使用的已安装能力，建议卸载节省资源” → [查看]
- 卡片背景为浅紫 `#F3F0FF`，左边框3px枢轴紫

## 2.3 明细对账页

### 2.3.1 布局
顶部筛选栏 + 表格列表 + 底部分页

### 2.3.2 筛选栏
- 时间范围选择器（日历组件，支持快捷：今天/本周/本月）
- 模型下拉多选
- Agent下拉多选
- 任务ID搜索框
- 金额范围输入
- “导出CSV”按钮、“导出Excel”按钮

### 2.3.3 明细表格
每列定义：
| 列名 | 宽度 | 说明 |
|------|------|------|
| 时间 | 140px | 精确到秒，格式 `HH:mm:ss` |
| 模型 | 100px | 模型名称，带色标 |
| Agent | 120px | Agent名称，可点击跳转管理页 |
| 任务ID | 80px | 截断显示，悬停完整展示，可复制 |
| 输入Token | 80px | 等宽字体，右对齐 |
| 输出Token | 80px | 等宽字体，右对齐 |
| 花费 | 80px | 右对齐，金额颜色根据大小变化 |
| 来源 | 60px | “估算”/“官方”，官方数据打绿勾 |
| 请求ID | 80px | 截断显示，可点击**聚焦**到该次调用的完整上下文 |

### 2.3.4 行聚焦交互
点击任意明细行的“请求ID”或行末聚焦按钮，右侧滑出**请求详情面板**：
- 完整请求体（JSON格式化，支持折叠）
- 完整响应体（JSON格式化，支持折叠）
- 请求耗时
- 关联的Agent配置信息
- 所属网关名称与延迟
- “查看关联任务”按钮（若有关联TaskID）

### 2.3.5 汇总行
表格底部固定汇总行：
- 总Token（输入+输出）
- 总花费
- 预估花费 vs 实际花费 对比（误差百分比）

## 2.4 预算管理页

### 2.4.1 布局
左侧设置表单 + 右侧实时预览

### 2.4.2 预算设置区
- 月度预算输入框（¥），带滑块快捷设定（¥100/500/1000/2000/自定义）
- “超预算后行为”单选框：
    - 仅提醒（默认）
    - 阻止新请求
    - 仅允许白名单模型
- 白名单模型配置：多选列表，超预算后仍可使用的模型
- 告警阈值滑块：默认80%/95%/100%三档，可自定义百分比

### 2.4.3 实时预览区
- 当前预算消耗进度条（大号，动态颜色）
- 按当前速率，预计耗尽日期
- “如果开启智能降本，预计可延长至X日”预测

### 2.4.4 预算变更日志
页面底部，表格形式记录历史预算变更：时间、旧值、新值、变更原因。

## 2.5 告警交互规范（全局通用）

| 触发条件 | 视觉表现 | 行为 |
|---------|---------|------|
| 预算达80% | 顶部黄色提醒条，不可关闭 | 持续显示 |
| 预算达95% | 弹窗通知 + 桌面通知 + 状态栏图标闪烁 | 用户需确认关闭 |
| 预算达100% | 全屏遮罩提示 + 所有API请求被拦截 | 需调整预算或等下个周期 |
| 消耗突增3倍 | Toast通知 + 面板红点 | 点击跳转溯源 |

# 三、模型网关配置

## 3.1 页面定位
用户管理所有模型服务商的地方：添加网关、配置密钥、测试连通性、设置默认策略。

## 3.2 布局
左侧网关列表（240px）+ 右侧配置详情（自适应）

## 3.3 网关列表

每个网关条目（高度48px）：
- 服务商图标（Ofox/302.AI/硅基流动/OpenAI官方/自定义）
- 名称
- 状态指示灯：🟢已连接 / 🟡延迟高 / 🔴不可用 / ⚫未配置
- 默认网关标识：枢轴紫小星标
- 点击切换右侧详情

列表底部“添加网关”按钮，点击弹出选择器：
- 预设网关（Ofox、302.AI、硅基流动、非线智能、OpenRouter等）
- “自定义网关”选项

## 3.4 配置详情区

### 3.4.1 基本信息卡片
- 网关名称（可编辑）
- Base URL（自动填充，可修改）
- API密钥输入框（密文显示，点击眼睛图标切换可见）
- “测试连接”按钮（点击后显示延迟毫秒数 + 可用模型列表）

### 3.4.2 可用模型列表
表格展示该网关支持的所有模型：
- 模型名称
- 输入价格（¥/百万Token）
- 输出价格（¥/百万Token）
- 上下文窗口
- 支持功能标签（函数调用/视觉/流式）
- 启用开关（可关闭不需要的模型，不在选择器中显示）

### 3.4.3 路由策略设置
- “设为默认网关”开关
- “作为备用网关”配置：当主网关不可用时自动切换
- 自定义模型路由规则（高级）：
    - “当任务类型为XX时，使用YY模型”
    - “当单次请求Token数超过N时，切换至ZZ模型”

## 3.5 一键连通性检测

页面顶部工具栏“检测全部”按钮，点击后所有已配置网关并发测试：
- 测试结果在列表中以微型进度条展示
- 全部通过：绿色Toast“所有网关正常”
- 部分失败：黄色Toast“X个网关异常，点击查看”
- 失败的网关在列表中展开错误详情（超时/认证失败/网络不通）

## 3.6 网关异常处理交互

当默认网关不可用时：
- 仪表盘系统状态变为黄色
- 自动尝试备用网关
- 若无备用网关，Agent运行时自动降级为官方直连
- 客户端推送通知“默认网关异常，已自动切换”

# 四、Agent运行时管理器

## 4.1 页面定位
Agent全生命周期控制中枢。用户在此完成从框架选择、一键部署、启动运行、监控管理到故障排查的完整闭环。

## 4.2 框架选择页

### 4.2.1 布局
顶部引导语 + 搜索筛选栏 + 卡片网格 + 底部已安装快速入口

### 4.2.2 引导语区域
- 首次访问（无任何Agent）：
  - 居中大标题：“选择你的第一个Agent框架”
  - 副标题：“枢元支持所有主流框架，一键部署，统一管理”
  - 下方三个引导卡片：LangGraph（推荐）、CrewAI、OpenClaw
- 已有Agent：
  - 顶部小字：“已安装 X 个Agent”，右侧“添加新框架”按钮

### 4.2.3 搜索与筛选栏
- 搜索框：支持按框架名称、描述关键词搜索
- 筛选标签组（横向排列，可多选）：
  - 按场景：全部 / 办公自动化 / 编程开发 / 数据分析 / 本地推理
  - 按难度：全部 / 新手友好 / 需要配置 / 开发者级
  - 按状态：全部 / 已安装 / 未安装
- 排序：推荐 / 热门 / 最新

### 4.2.4 框架卡片（每张卡片规格）

**卡片尺寸**：宽280px，高200px，`border-radius: 8px`，白底

**卡片内容**（从上至下）：
- 顶部：框架图标（40x40px）+ 框架名称（16px半粗体）+ 难度标签（圆角小胶囊）
- 中间：一句话描述（14px，`#6B7280`，最多2行）
- 底部：操作按钮区域

**难度标签颜色**：
- 新手友好：绿色底 `#D1FAE5`，文字 `#059669`
- 需要配置：橙色底 `#FEF3C7`，文字 `#D97706`
- 开发者级：灰色底 `#F3F4F6`，文字 `#4B5563`

**操作按钮**（根据安装状态变化）：
- 未安装：[一键安装] 主按钮，点击进入部署向导
- 安装中：[安装中...] 加载按钮，显示进度百分比
- 已安装：[打开] 次要按钮 + [启动] 主按钮
- 运行中：[打开控制台] 次要按钮 + [停止] 危险按钮

**已安装标识**：卡片右上角绿色小勾

**悬停态**：卡片上浮阴影 + 边框变枢轴紫

### 4.2.5 首次使用引导
- 首个“推荐”框架卡片出现脉冲光效（与聚焦呼吸光效相同）
- 卡片右下角浮动气泡：“从这里开始，只需3步”

### 4.2.6 已安装快速入口
页面底部固定栏（高度48px），横向排列已安装Agent的微型图标，点击直接跳转控制台。

---

## 4.3 Agent控制台（运行时主页）

### 4.3.1 布局
采用主内容区 + 右侧状态面板的经典布局。主内容区包含：状态头、快捷操作栏、运行图/日志切换标签页。右侧面板显示Agent详情与实时指标。

```
┌──────────────────────────────────────────────────────────────┐
│ ← 返回列表    Agent名称 [框架标签]  状态指示灯               │
├────────────────────────────────┬─────────────────────────────┤
│ [启动][停止][重启] [配置] [日志]│  Agent详情                  │
│                               │  框架: LangGraph v0.3       │
│ ┌─ 运行图 ──┬─ 日志 ──┐      │  状态: 运行中               │
│ │           │          │      │  运行时间: 2h 34min         │
│ │ 节点拓扑图│  日志流   │      │  Token消耗: 12,450         │
│ │           │          │      │  内存: 256MB               │
│ │           │          │      │  模型: GPT-4o (via Ofox)   │
│ │           │          │      │  端口: 18901               │
│ └───────────┴──────────┘      │                            │
│                               │  [查看配置] [导出日志]      │
├────────────────────────────────┴─────────────────────────────┤
│ 状态栏                                                        │
└──────────────────────────────────────────────────────────────┘
```

### 4.3.2 状态头区域
- 左上角：返回箭头 + Agent名称（可编辑，点击变为输入框）
- 名称右侧：框架标签胶囊（如 `LangGraph` 蓝底白字）
- 最右侧：状态指示灯 + 状态文字
  - 🟢 运行中（绿色）
  - 🟡 异常（橙色，附错误摘要）
  - 🔴 已停止（灰色）
  - 🔵 启动中/停止中（蓝色，带旋转动画）

### 4.3.3 快捷操作栏
横向排列的图标按钮组，每组带tooltip：
- [启动] 绿色播放图标
- [停止] 红色停止图标
- [重启] 橙色刷新图标
- [配置] 灰色齿轮图标
- [日志] 灰色文档图标
- [终端] 灰色终端图标（点击打开内嵌终端）

**按钮状态**：根据Agent状态动态禁用/启用（如运行中禁用“启动”，已停止禁用“停止”）

### 4.3.4 运行图标签页（拓扑聚焦交互）

**核心组件**：交互式节点图，基于React Flow实现。

**节点设计**：
- 每个节点为一个圆角矩形卡片，内部显示节点名称 + 状态图标 + 微型耗时条
- 节点颜色：
  - 执行中：蓝色边框 + 呼吸光效
  - 已完成：绿色实心 + 对勾
  - 失败：红色边框 + 感叹号
  - 待执行：灰色虚线边框
- 节点间连线：贝塞尔曲线，执行过的连线为实线枢轴紫，未执行的为虚线灰

**聚焦交互**：
- 点击任意节点 → 右侧滑出聚焦面板“节点详情”
- 面板内容（详见设计规范修订版4.5节）：
  - 节点输入输出数据（JSON，可折叠）
  - 执行耗时 + Token消耗条形图
  - 错误详情（失败节点专属）
  - 兄弟节点状态列表（半透明展示）
- 面板底部：失败节点专属[重试此步骤]按钮

**视图操作**：
- 滚轮缩放
- 拖拽平移
- 右下角小地图（minimap）
- “适应画布”按钮
- “导出为图片”按钮

**自动聚焦**：当运行图中出现失败节点时，画布自动平移到该节点并触发聚焦面板展开。

### 4.3.5 日志标签页

**顶部工具栏**：
- 搜索框（支持关键词过滤）
- 等级筛选：全部 / INFO / WARN / ERROR / DEBUG
- 时间范围筛选
- “自动滚动”开关（默认开启）
- “聚焦异常”按钮（一键定位第一条ERROR）
- “清屏”按钮
- “导出”按钮

**日志流区域**：
- 等宽字体 `JetBrains Mono`，13px
- 行号左侧显示
- 颜色规则：
  - INFO：默认灰
  - WARN：橙 `#F59E0B`
  - ERROR：红 `#EF4444` + 浅红背景行
  - DEBUG：浅灰 `#9CA3AF`
- 每行可点击选中，选中后高亮背景

**聚焦交互**：
- 点击任意ERROR行 → 右侧滑出“问题透视”面板（与部署向导错误聚焦共用组件）

### 4.3.6 右侧Agent详情面板（280px，常驻）

# 五、部署向导

## 5.1 页面定位
将Agent框架安装这一复杂操作封装为线性可控的步骤流，每一步只做一件事，失败时提供聚焦排查能力。

## 5.2 布局
左侧垂直步骤条 + 中央操作区（日志流+表单） + 右侧聚焦面板（默认隐藏）

```
┌──────────────────────────────────────────────────────────────┐
│ 部署向导：LangGraph                          [最小化] [关闭]  │
├────────┬─────────────────────────────────┬────────────────────┤
│ 步骤条  │  操作区                         │  聚焦面板（隐藏）   │
│        │                                 │                    │
│ ✓ 1   │  当前步骤的日志流 / 表单          │                    │
│ ✓ 2   │  ┌─────────────────────────┐    │                    │
│ ● 3   │  │ $ pip install langgraph │    │                    │
│ ○ 4   │  │ Collecting langgraph... │    │                    │
│ ○ 5   │  │ Successfully installed  │    │                    │
│ ○ 6   │  └─────────────────────────┘    │                    │
│ ○ 7   │                                 │                    │
│        │  [上一步]  [下一步]  [跳过]      │                    │
├────────┴─────────────────────────────────┴────────────────────┤
│ 状态栏                                                         │
└──────────────────────────────────────────────────────────────┘
```

## 5.3 步骤条设计（左侧220px）

**步骤列表**（固定7步）：
1. 环境检测
2. 创建虚拟环境
3. 安装框架依赖
4. 配置模型密钥
5. 下载模型/配置（可选，可跳过）
6. 启动服务
7. 验证完成

**每步状态图标**：
- ✓ 已完成：绿色圆形对勾
- ● 进行中：蓝色圆形 + 旋转动画
- ○ 待执行：灰色空心圆
- ✗ 失败：红色圆形叉号 + 可点击（触发聚焦面板）
- ⏭ 已跳过：灰色横线

**步骤文字**：
- 已完成步骤：灰色文字
- 当前步骤：枢轴紫加粗
- 待执行步骤：浅灰文字
- 失败步骤：红色文字 + 右侧出现“？”聚焦按钮

**步骤条底部**：整体进度百分比 + 预计剩余时间

## 5.4 操作区设计（中央自适应）

### 5.4.1 日志流区域
- 终端风格，黑底（`#1E1E1E`），等宽字体
- 实时滚动，ANSI颜色转义支持
- 每行左侧行号
- 自动滚动开关（右下角）
- 搜索框（顶部右侧）

### 5.4.2 表单区域（仅配置步骤出现）
- 模型选择下拉（含搜索）
- API密钥输入框（密文，带可见切换）
- Base URL输入框（自动填充当前默认网关）
- 测试连接按钮

### 5.4.3 底部操作栏
- [上一步]：次要按钮（第一步时禁用）
- [下一步]：主按钮
- [跳过]：仅可选步骤出现（如步骤5）
- [取消]：文字按钮，弹出确认对话框

### 5.4.4 步骤间过渡
- 步骤完成 → 自动前进（延迟1s，让用户看到成功状态）
- 也可手动点击[下一步]立即前进

## 5.5 错误处理与聚焦排查

### 5.5.1 错误状态的视觉呈现
- 步骤条：当前步骤图标变红✗，文字变红
- 日志流：错误行标红，背景浅红
- 底部操作栏：出现[一键修复]主按钮（枢轴紫）+ [聚焦排查]按钮（带准星图标）

### 5.5.2 聚焦面板：“问题透视”
**触发方式**：
- 点击失败步骤的“？”图标
- 点击日志流中的ERROR行
- 点击底部[聚焦排查]按钮

**面板内容结构**（自上而下）：
1. **根因分析卡片**（固定在顶部，浅紫背景 `#F3F0FF`）
  - 错误码（如 `VENV_CREATE_FAILED`）
  - 中文根因描述（如“虚拟环境创建失败：pip版本过低”）
  - 影响说明（如“此步骤失败将无法继续安装”）

2. **上下文日志区**（等宽字体，黑底）
  - 展示错误发生前后20行日志
  - 错误行高亮红色背景
  - 支持复制

3. **解决方案区**（如有社区方案）
  - 标题：“社区解决方案”
  - 方案卡片列表，每张包含：
    - 方案标题
    - 操作步骤（1/2/3步）
    - [一键应用] 按钮
  - 若无可选方案，显示“暂无相关解决方案”

4. **手动修复终端**（底部固定区）
  - 迷你终端，可直接输入命令
  - 输入命令后回车执行
  - 执行结果显示在终端中
  - [重试当前步骤] 按钮

5. **一键求助引导**（底部轻提示）
  - “以上方案无效？发布求助帖”
  - 点击后自动生成草稿（含环境信息、错误日志、脱敏配置）
  - 跳转至社区发帖页（预填充草稿）

### 5.5.3 修复成功后的反馈
- 步骤条恢复为✓
- 聚焦面板显示“修复成功”绿色提示
- 自动前进到下一步（延迟1.5s）

## 5.6 步骤详细设计

### 步骤1：环境检测
- 三级检测（系统/依赖/网络），每项检测结果实时显示
- 通过：绿色✓
- 警告：橙色⚠ + 说明（不阻断）
- 失败：红色✗ + 修复引导
- 全部通过后自动激活[下一步]按钮

### 步骤2：创建虚拟环境
- 显示创建路径
- Python版本确认
- 实时日志流

### 步骤3：安装框架依赖
- 显示依赖列表（可展开查看具体包名和版本）
- 实时日志流
- 镜像源自动切换（HuggingFace不可达→国内镜像）

### 步骤4：配置模型密钥
- 表单：选择网关 + 输入密钥 + 测试连接
- 测试连接结果：绿色“连接成功，延迟XXms” 或 红色“连接失败：原因”
- 密钥仅本地加密存储

### 步骤5：下载模型/配置（可选）
- 显示模型列表（名称 + 大小）
- 可跳过（“稍后手动下载”）
- 下载进度条 + 速度显示

### 步骤6：启动服务
- 启动命令展示
- 服务状态轮询（每2秒）
- 启动成功：端口号显示 + 进程ID显示

### 步骤7：验证完成
- 发送测试请求验证
- 显示“部署成功”大号绿色对勾
- 烟花粒子特效（Lottie，极简）
- “打开Agent控制台”按钮 + “安装能力市场工具”引导

## 5.7 向导窗口行为

- 可最小化到任务栏，后台继续执行
- 关闭时检测进行中的步骤，弹出确认：“部署正在进行中，关闭后将丢失进度。确定关闭？”
- 意外关闭后，重新打开时检测残留进程，提供“继续上次部署”/“重新开始”选择
